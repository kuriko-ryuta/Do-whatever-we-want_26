# GitHub練習リポジトリ

このリポジトリは、GitHubの基本操作（clone / branch / commit / push / Pull Request・コンフリクト解消など）を、実際に手を動かして覚えるための練習用リポジトリです。

## お約束

- **好きに触って大丈夫です。** 壊れても他の人がすぐ直せる内容しか入っていません。
- この練習リポジトリの中では、`main` への直接pushもforce pushも自由に行って構いません（通常の業務用リポジトリでは基本的に禁止されている操作なので、その違いは意識しておいてください）。
- 進め方に迷ったら [EXERCISES.md](./EXERCISES.md) の順番通りに進めてください。

## このリポジトリの内容

私たちが普段行っている「データ分析 → 結果をHTMLで出力する」という業務の流れに寄せて、`index.html` という架空の分析レポートを用意しています。このHTMLを書き換えながら、Gitの基本操作を練習していきます。

| ファイル | 内容 |
|---|---|
| `index.html` | 架空の月次売上分析レポート（練習で書き換えていく対象） |
| `EXERCISES.md` | 練習課題を難易度順に並べたリスト |
| `.gitignore` | 分析作業で発生しがちな不要ファイルを除外する設定例 |

## レポートの見方

`index.html` はブラウザでそのまま開けます。ファイルをダブルクリックするか、VS Codeの「Live Preview」拡張機能や、ブラウザへのドラッグ&ドロップで確認してください。
